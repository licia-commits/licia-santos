# Lícia Santos Advocacia — site

Site one-page da Lícia Santos, advogada de Direito Médico e da Saúde em Natal-RN.
HTML, CSS e JS puros, sem build. É só abrir o `index.html` no navegador.

No ar: https://licia-santos-advocacia-blush.vercel.app

## Arquivos

- `index.html`: todo o conteúdo. Seções na ordem: hero (`#inicio`), manifesto, áreas de atuação (`#atuacao`), sobre (`#sobre`), depoimentos (`#depoimentos`), como funciona (`#processo`), falso coletivo, dúvidas (`#duvidas`), contato (`#contato`).
- `style.css`: estilos, com as cores e fontes definidas em variáveis no topo.
- `script.js`: menu, animações de entrada, carrossel e FAQ.
- `assets/`: fotos (webp), logos, monograma e prints de depoimentos.
- `Referências/`: imagens de referência visual usadas no projeto (não entram no site).

## Identidade

- Estética editorial monocromática, predominantemente clara, sem cor de destaque. Os botões são pretos ou ghost.
- Cores: marfim `#FBFAF7`, branco `#FFFFFF`, tinta `#14161A`, grafite `#23262C`, cinza `#6C6F76`, linha `#E7E3DB`.
- Fontes: General Sans (Fontshare) em títulos e textos, Space Mono (Google Fonts) em rótulos e números. Títulos com peso 400.
- O serifado aparece só no logo.
